# Calculator — OASIS INFOBYTE Level 2 Task 1

## Project Overview

A browser-based calculator developed using HTML5, CSS3, and vanilla JavaScript. It performs basic arithmetic operations through a simple, responsive button interface.

## Features

* Numeric buttons from 0 to 9
* Addition, subtraction, multiplication, and division
* Decimal number support
* Expression and result display
* Clear button to reset the calculator
* Backspace button to delete the last character
* Operator chaining with standard arithmetic precedence
* Division-by-zero error handling
* Keyboard input support
* Responsive layout using CSS Grid
* Event listeners for button interactions
* Expression evaluation without using `eval()`

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run a local server, or open `index.html` in a browser.
4. Use the calculator buttons or keyboard to perform calculations.

## Example

Expression: `5 + 3 × 2`

Result: `11`

Division-by-zero example: `8 ÷ 0`

Expected output: An error message indicating that division by zero is not allowed.
