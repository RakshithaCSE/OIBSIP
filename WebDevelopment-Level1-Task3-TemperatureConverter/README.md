# Temperature Converter Website

A responsive temperature converter website developed as part of the **OASIS INFOBYTE Web Development & Designing Internship – Level 1, Task 3**.

## Project Overview

This website allows users to convert temperatures between:

* Celsius (°C)
* Fahrenheit (°F)
* Kelvin (K)

The application provides a simple, clean, and responsive interface with input validation.

## Features

* Convert Celsius to Fahrenheit and Kelvin
* Convert Fahrenheit to Celsius and Kelvin
* Convert Kelvin to Celsius and Fahrenheit
* Input validation for empty or invalid values
* Responsive design for different screen sizes
* Clear conversion result display

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.
5. Enter a temperature, select the source and target units, and click **Convert**.

## Conversion Examples

* 100°C = 212°F
* 32°F = 0°C
* 273.15K = 0°C
