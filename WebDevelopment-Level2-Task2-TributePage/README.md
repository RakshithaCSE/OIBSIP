\# Dr. A. P. J. Abdul Kalam — Tribute Page



\## Project Overview



A responsive tribute website dedicated to Dr. A. P. J. Abdul Kalam, scientist, teacher, and former President of India. The page highlights his life, achievements, and legacy.



\## Features



\* Hero section with title and portrait

\* Biography with original summary content

\* Timeline of major achievements

\* Styled quotation section

\* Legacy section and official biography link

\* Navigation links

\* Contrasting section backgrounds

\* Serif headings and sans-serif body typography

\* Responsive desktop and mobile layout

\* Image attribution and reference links



\## Technologies Used



\* HTML5

\* CSS3

\* CSS Grid

\* Flexbox

\* Responsive Web Design



\## Project Files



\* `index.html` — Page structure and content

\* `style.css` — Styling and responsive layout

\* `README.md` — Project documentation

\* `screenshots/` — Project screenshots



\## How to Run



1\. Open the project folder in Visual Studio Code.

2\. Open a terminal in the folder.

3\. Run `python -m http.server 8001`.

4\. Visit `http://localhost:8001` in a browser.
