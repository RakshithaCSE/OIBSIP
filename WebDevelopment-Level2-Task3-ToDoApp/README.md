# TaskFlow — To-Do Web App

## Project Description

A simple and responsive To-Do Web App that allows users to add, edit, complete, and delete daily tasks efficiently.

## Features

* Add new tasks
* Edit task descriptions
* Mark tasks as completed or move them back to pending
* Delete tasks
* Separate pending and completed task lists
* Display pending and completed task counts
* Show task timestamps
* Save tasks across page refreshes using localStorage
* Display helpful messages when task lists are empty
* Responsive interface for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Browser localStorage

## Project Files

* `index.html` — Application structure
* `style.css` — Styling and responsive layout
* `script.js` — Task management functionality
* `README.md` — Project documentation

## How to Run

1. Open the project folder in Visual Studio Code.
2. Start a local server by running `python -m http.server 8002`.
3. Open `http://localhost:8002` in your browser.
