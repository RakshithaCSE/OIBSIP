## Project Description

NovaTech is a modern static landing page created using HTML5 and CSS3. The website presents a fictional technology brand with a clean and responsive design.

## Features

- Sticky navigation bar
- Home, Features, About, and Contact links
- Hero section with headline and CTA button
- Three feature cards
- About section
- Contact section
- Footer with social media links
- Responsive design
- CSS Grid and Flexbox
- Consistent color palette
- Clean typography and spacing

## Technologies Used

- HTML5
- CSS3
